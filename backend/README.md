# Backend — API de Clubes (Fase 1)

API REST em Node.js + Express + mysql2, responsável pelo CRUD de
clubes. Veja o README na raiz do projeto (`sistema-clubes/README.md`)
para instruções completas de instalação, endpoints e explicações
didáticas.

## Comandos

```bash
npm install
cp .env.example .env   # depois edite com os dados do seu MySQL
npm run dev
```

Servidor sobe em `http://localhost:3001`.
